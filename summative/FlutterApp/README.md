# Breach Impact Estimator (Flutter)

A one-page app that calls `POST https://linear-regression-model-ftfw.onrender.com/predict`.

* `lib/api_service.dart`: the API call (URL, JSON body, timeout, readable error messages)
* `lib/main.dart`: the page (12 labelled text fields, a **Predict** button, and the result/error area)

Run it with the steps in the repository README.
